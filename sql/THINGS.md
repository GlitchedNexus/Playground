# What I learned

Types of SQL Commands:
1. DDL (Data Definition Language) : Used for working on tables
  - CREATE: Create a new DB / Table
  - ALTER: Modify
  - DROP: Delete (no backups)
  - TRUNCATE: Delete data not the table
2. DML (Data Manipulation Language) : Used for manipulating rows
  - INSERT: Add data
  - UPDATE: Modify data
  - DELETE: Delete data
3. DQL (Data Query Language) : Used to filter data and get specific results
  - SELECT: Fetch Data
